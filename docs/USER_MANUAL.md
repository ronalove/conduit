# Knights Network - Manuel Utilisateur

## Introduction

Knights Network est un client IRC moderne avec support complet IRCv3.

## Premiers Pas

### Connexion

1. Lancer l'application
2. Entrer vos identifiants (username/password)
3. L'application se connecte automatiquement au serveur

### Interface

#### Desktop (Windows/macOS)
- **Colonne gauche** : Liste des channels
- **Centre** : Zone de chat
- **Colonne droite** : Liste des utilisateurs

#### Mobile (iOS/Android)
- **Navigation** : Bottom bar ou drawer
- **Chat** : Vue plein ecran
- **Utilisateurs** : Accessible via swipe ou bouton

## Fonctionnalites

### Messages
- Envoyer des messages dans les channels
- Repondre a des messages specifiques
- Voir l'indicateur de frappe

### Channels
- Rejoindre/quitter des channels
- Voir la liste des membres
- Consulter l'historique

### Utilisateurs
- Voir le statut (online/away)
- Envoyer des messages prives
- Surveiller des utilisateurs (Monitor)

## Raccourcis Clavier (Desktop)

| Raccourci | Action |
|-----------|--------|
| Ctrl+Enter | Envoyer message |
| Ctrl+K | Rechercher channel |
| Ctrl+/ | Ouvrir aide |
